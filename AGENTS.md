# Flujo de trabajo de SmartCapture

En `kameXD/CCNA2`, cuando completes y verifiques una modificación solicitada, crea un commit con sus cambios y súbelo directamente a `origin/main`, salvo que el usuario indique otra cosa para esa tarea. Incluye únicamente los cambios de la tarea, conserva el historial remoto y evita los pushes forzados. Comprueba que GitHub recibió el commit e informa si los permisos o las protecciones de rama impiden el push.
